# Archives du lore

Sources brutes sorties de `docs/lore/` : **hors canon** et hors de `/admin/lore`. Le lore vivant ne garde que les récits (le décidé et les propositions `?{…}?`) ; tout ce qui les a produits est ici, tel qu'il était.

- **Même arborescence que `docs/lore/`** : la séance complète de `docs/lore/cites/x.md` (messages de l'Auteur, réponses de ChatGPT, tableaux d'arbitrage) est `docs/archives/lore/cites/x.md`. Chaque séance du lore cite ce chemin dans son en-tête « 🗂 Échanges de travail ».
- **Séances fusionnées ou retirées** (24/11/2026) : leur fichier n'existe plus dans le lore, seulement ici ; la séance qui les a reprises le dit dans son en-tête.
