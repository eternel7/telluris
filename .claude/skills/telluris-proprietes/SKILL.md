### Propriétés résidentielles (`utils/proprietes.py`, `routers/proprietes.py`)
- **Type FIGÉ** : Chambre → Logement → Maison → Demeure → Domaine. Aucune conversion ; seule `creer_propriete` pose `type_propriete` (verrouillé par `test_aucune_fonction_ne_reecrit_le_type`). Monter en gamme = céder puis acquérir ; les aménagements **restent sur le bien cédé**.
- **Doc `propriete:<type>_<hex12>`** (état de partie, hors `_CACHEABLE_PREFIXES`) : forme d'un lieu sans grille (`label`, `image`, `categorie:"propriete"`, `lieu_parent`) mais `type:"propriete"` — les balayages `find_docs({"type":"lieu"})` ne le voient pas. Relié par un `link:*` à la case d'achat (`origine`), visible de tous.
- **Personnage** : `proprietes` (index, preuve = index + `proprietaire`, comme `montures`), `residence` (une seule). Champs absents ⇒ rien.
- **Données** : `rules:proprietes` = `{types, amenagements, metiers}`. La contrainte de type est `amenagements[].types_autorises` ; `capacite` = `occupants` / `stockage_kg` / `postes {metier: n}` ; `activite {metier, label}` ; `effets.garde`. Capacités **dérivées** (`capacites`), jamais stockées.
- **Achat** : case d'une ville (`categorie:"ville"`) couverte par une zone peinte `zone:habitable_<type>` (doc `zone_influence` portant `type_propriete`, `intensite_max: 0` ⇒ aucun effet sur les tirages ; l'appartenance passe par `zones.est_dans_zone`). Peindre les zones avec l'outil de zones de l'éditeur.
- **Location** : type porteur de `location {prix_cuivre, duree_s}` (la Chambre), dans une auberge. **Inviolable** : lien caché aux autres (`get_lieu_links`), entrée refusée (`move_character`, garde propre hors kill-switch `ACCES_GARDIEN_ACTIF`). Péremption **paresseuse** (`traiter_expiration_location` : `/play`, `move_character`, `_ici`, nuit). Expirée : le locataire récupère ses affaires, n'y dort plus ; relouer prolonge la MÊME chambre.
- **Personnel** : `employe:*` attaché à UNE propriété, engagé sur un **poste** (aménagement installé + métier), sous `personnel_max`. L'espace ne crée jamais le PNJ. Activité « exercée » ssi un employé du métier est au poste — rien n'est produit (passe structurelle).
- **Vol** : chez un propriétaire, un visiteur peut `retirer` du coffre tant qu'aucun `gardien` n'est au poste d'un aménagement `effets.garde` (`loge_gardien`, ouverte aux cinq types). Dépôt : propriétaire/locataire seulement, borné par `stockage_kg`.
- **Compagnons hébergés** : quittent `character.groupe`, prennent `loge_a` (statut `embauche` conservé ⇒ `groupe_effectif` les ignore sans code). `reprendre` respecte `places_occupees`. Borné par `occupants_max` (résident compris).
- **Céder** (vendre/abandonner) : coffre vide et aucun hébergé ; personnel renvoyé ; lien supprimé ; le personnage est **reconduit sur la case d'origine** (`/play` expulse aussi quiconque se trouve dans un bien qui ne l'admet plus). Revente = `prix_cuivre × revente_facteur` du type (0 ⇒ invendable), fermée si la cité porte `proprietes.revente: false`.
- **Nuit** : `routers/auberge._acces_nuit` — gratuite chez soi (propriétaire ou locataire valide), même flux que l'auberge.
- **UI** : boutons « 🏠 Propriétés » (`proprietes_offre`) et « 🏠 Gérer le logis » + « 🌙 Passer la nuit » (`est_propriete`) ; `#proprietes-panel`, vues `renderProprietesOffre` / `renderPropriete`, entrée Échap. Harnais `dev/test_proprietes_client.js`.
- Tests : `tests/test_proprietes.py` (pur + catalogue LIVRÉ relu), `tests/test_proprietes_endpoints.py`, `tests/test_lieux_acces.py` (visibilité des liens).
- Images des types : **provisoires** (auberge, maison des arts, chemin) — `/play` lève 404 sur une image absente, `test_livre_images_presentes` le verrouille.
