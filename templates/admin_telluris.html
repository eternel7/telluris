Import de documents
⇪ Import JSON → CouchDB
Import en masse de documents. Format accepté : un tableau d'objets ([ { … }, … ]) ou le format _bulk_docs ({ "docs": [ … ] }). Import file charge un fichier dans la zone ; vous pouvez aussi y coller le JSON directement. Les documents existants (même _id) sont mis à jour.

Variables de monde
📜 rules:world_variables
Variables d'équilibrage chargées depuis CouchDB (doc rules:world_variables), avec repli sur les valeurs par défaut du code. Éditez le JSON ci-dessous puis Save pour persister en base ; Reload applique le doc à chaud (sans redéploiement) et rafraîchit l'affichage.
