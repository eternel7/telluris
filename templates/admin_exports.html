Dump CouchDB
Export JSON des documents de la base telluris (design docs inclus), avec leurs _id/_rev. Les documents user:* sont inclus (restauration à l'identique) : le fichier contient les empreintes de mot de passe — ne pas le committer tel quel. Ré-importable via l'API CouchDB _bulk_docs.
⬇ Télécharger le dump (.json)
Dump committable (sans user:*)
Le même dump que celui qu'écrivent les outils de /admin/dev-tools et les générateurs dev/gen_*.py (code commun : utils/dump.py) : format identique, mais sans les documents user:*. Sans empreinte de mot de passe, il se dépose tel quel dans jsons/ et se committe.
⬇ Télécharger le dump committable (.json)
Dump → branche git + PR vers main
Génère le dump committable (sans user:*) sur le serveur, le commite dans jsons/ sur une nouvelle branche admin/dump-AAAAMMJJ-HHMMSS partant du main distant, la pousse et ouvre une pull request vers main. L'arbre de travail et la branche courante du serveur ne bougent pas. PR créée si GITHUB_TOKEN est défini dans le .env ; sinon, lien pour l'ouvrir à la main.
